## Why you couldn't register

It wasn't a bug in the form. The server had this line hard-coded:

```ts
const AUTHORIZED_USER = 'Srimani26'
...
if (username !== AUTHORIZED_USER) return c.json({ error: 'Unauthorized user' }, 403)
```

**Any username other than `Srimani26` was rejected on purpose.** And `Srimani26` itself already existed → `409 Account already exists`. So the Register button could never succeed. Your account also had `failedAttempts: 1`, meaning a login attempt had already failed.
